# Kreative Core Company Roadmap

## Stage 1 — Stabilization

### Objectives

- Audit the repository and product claims
- Confirm which products have working code
- Fix critical website and deployment defects
- Establish worker organization
- Create issue labels and templates
- Establish QA, security, and release gates
- Document payment architecture

### Exit Criteria

- Product inventory is evidence-based
- Critical broken links are fixed
- Build and deployment paths are known
- Secrets are not present in source control
- Every active project has an owner

## Stage 2 — Productization

### Objectives

- Package installable products
- Complete setup and user documentation
- Define licensing and support
- Implement order and delivery states
- Build IBAN payment workflow
- Add secure admin verification
- Create release notes and rollback procedures

### Exit Criteria

- At least one product can be purchased, verified, delivered, and supported end-to-end
- QA and security approval are documented
- Owner has approved pricing and activation

## Stage 3 — Growth

### Objectives

- Launch product campaigns
- Improve SEO and content
- Collect customer feedback
- Measure conversion and support demand
- Build a repeatable release cadence
- Evaluate new products based on validated demand

### Exit Criteria

- Marketing activity has measurable goals
- Customer feedback affects the roadmap
- Product maintenance ownership is defined

## First 30-Day Backlog

1. Repository and product audit
2. Product readiness verification
3. Broken link and navigation review
4. Build and deployment validation
5. Security and secret scan
6. Payment architecture review
7. IBAN workflow prototype
8. Order and delivery data model
9. QA checklist and release gate
10. Owner decision list for pricing, bank details, invoicing, and launch
