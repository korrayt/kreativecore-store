- Product name

- Target user
- Current status

- Technical stack
- Missing capabilities
- Known defects
- Commercial value
- Risks
- Dependencies
- Product owner

- QA owner
- Marketing owner
- Next milestone
- Completion criteria

## Product Readiness Checklist

A product may move to `ready-for-release` only when:

- Working code exists
- Installation is possible
- Documentation exists
- Tests have been run
- Distribution package exists
- Licensing is defined
- Support path is defined
- Product page matches reality
- Purchase or download path works
